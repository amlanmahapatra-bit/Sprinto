User interface → pipeline → AI layer → external APIs → data → human review → send → measure. Arrows show data flow.

→

Flow: domains → pages → evidence → qualification → contact → 2 pains → draft → human review gate → email to demo inbox → opens and edit ratio.  Guardrails: every send is hard-asserted to one recipient, no fact without a quote and URL, no LinkedIn scraping.
